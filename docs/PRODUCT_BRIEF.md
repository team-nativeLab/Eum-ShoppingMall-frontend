# 제품 의도 브리프

마지막 확인: 2026-11-24

- 핵심 사용자: 산업 안전용품을 찾고 구매하는 개인회원 (사업자 회원 가입은 제공하지 않음) (출처: 사용자 확인, 2026-11-23)
- 왜 중요한지: 현장에 필요한 안전용품을 쉽게 찾아 구매하도록 돕기 위함 (출처: 사용자 요청, 2026-11-15)
- 가장 중요한 것: 전체 메뉴의 제품 카테고리와 전체 상품 목록에서 원하는 상품을 찾고 구매 흐름을 시작하기. 홈은 베스트·할인·추천 상품을 보여 주며 오늘의 상품 전용 기능은 제공하지 않습니다 (출처: 사용자 확인, 2026-11-24)
- 포기할 수 있는 것: 핵심 이동 흐름에 직접 연결되지 않는 프로모션 표현의 완성도 (출처: 사용자 확인)
- 이렇게 한 이유: 안전용품 쇼핑몰의 주요 상품 탐색 경로를 단순하게 제공하고, 가격 미표시 상품은 고객센터 문의로 안내하기 위함 (출처: 사용자 확인, 2026-11-23; 최초 확인, 2026-11-15)

## 변경 이력

- 2026-11-09: 최초 작성. 사용자가 제안된 브리프 내용을 확인함.
- 2026-11-16: 사용자가 주요 구매자 메뉴를 제품·베스트·오늘의 상품·브랜드몰로 확정해 가치·우선 경험·선택 이유를 갱신함.
- 2026-11-18: 사용자가 메가메뉴에서 베스트·오늘의 상품·브랜드몰(및 맞춤 제작/납품) 열을 빼기로 하고, '가장 중요한 것' 항목을 이에 맞게 수정함(사용자 확인).
- 2026-11-23: 사용자가 웹은 개인회원만 지원하도록 확정해 핵심 사용자를 갱신함.
- 2026-11-23: 사용자가 견적 신청·관리 흐름을 제거하고 가격 미표시 상품을 실제 고객센터 문의로 접수하도록 확정함.
- 2026-11-23: 사용자가 맞춤 제작·납품도 견적 관련 기능으로 보고 전용 카테고리와 진입을 삭제하도록 확정함(사용자 확인: “맞춤 제작-납품 또한 견적 관련 기능이니 삭제해놔.”).
- 2026-11-24: 사용자가 홈 쇼케이스와 전용 경로, 관리자 설정, API 지원을 포함한 오늘의 상품 기능 전체 제거를 확인함.
