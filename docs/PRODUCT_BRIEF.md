# 제품 의도 브리프

마지막 확인: 2026-11-27

- 핵심 사용자: 산업 안전용품을 찾고 구매하는 개인회원 (사업자 회원 가입은 제공하지 않음) (출처: 사용자 확인, 2026-11-23)
- 왜 중요한지: 현장에 필요한 안전용품을 쉽게 찾아 구매하도록 돕기 위함 (출처: 사용자 요청, 2026-11-15)
- 가장 중요한 것: 전체 메뉴의 제품 카테고리와 전체 상품 목록에서 원하는 상품을 찾고 구매 흐름을 시작하기. 홈은 베스트·할인·추천 상품을 보여 주며 오늘의 상품 전용 기능은 제공하지 않습니다 (출처: 사용자 확인, 2026-11-24)
- 포기할 수 있는 것: 핵심 이동 흐름에 직접 연결되지 않는 프로모션 표현의 완성도 (출처: 사용자 확인)
- 이렇게 한 이유: 안전용품 쇼핑몰의 주요 상품 탐색 경로를 단순하게 제공하고, 가격 미표시 상품은 고객센터 문의로 안내하기 위함 (출처: 사용자 확인, 2026-11-23; 최초 확인, 2026-11-15)

## 변경 이력

- 2026-11-09: 최초 작성. 사용자가 제안된 브리프 내용을 확인함.
- 2026-11-16: 사용자가 주요 구매자 메뉴를 제품·베스트·오늘의 상품·브랜드몰로 확정해 가치·우선 경험·선택 이유를 갱신함.
- 2026-11-18: 사용자가 메가메뉴에서 베스트·오늘의 상품·브랜드몰(및 맞춤 제작/납품) 열을 빼기로 하고, '가장 중요한 것' 항목을 이에 맞게 수정함(사용자 확인).
- 2026-11-23: 사용자가 웹은 개인회원만 지원하도록 확정해 핵심 사용자를 갱신함.
- 2026-11-23: 사용자가 견적 신청·관리 흐름을 제거하고 가격 미표시 상품을 실제 고객센터 문의로 접수하도록 확정함.
- 2026-11-23: 사용자가 맞춤 제작·납품도 견적 관련 기능으로 보고 전용 카테고리와 진입을 삭제하도록 확정함(사용자 확인: “맞춤 제작-납품 또한 견적 관련 기능이니 삭제해놔.”).
- 2026-11-24: 사용자가 홈 쇼케이스와 전용 경로, 관리자 설정, API 지원을 포함한 오늘의 상품 기능 전체 제거를 확인함.
- 2026-11-27: 상품 탐색·검색 API slice 작업 전 브리프가 여전히 맞는지 확인했고, 사용자가 “그대로 맞음 (추천)”이라고 답함.
- 2026-11-27: 상품 상세 API 계약에서 옵션 그룹 부재, SKU 가격의 절대가/추가금 의미, 배송·구매 안내 필드 부재에 대해 사용자가 “이 부분은 브리프로 남기고 후속 작업”이라고 답함. 세 항목은 미결정으로 남기고 별도 후속 작업에서 확인함.
- 2026-11-27: 상품 상세 API slice에서 사용자가 “mock에서 실제 서버 작업으로 변경까지해. 누락된 api은 클릭시 문구로 안내해줘.”라고 답함. real mode는 지원되는 실제 서버 응답을 사용하고, 미지원 기능은 mock 동작으로 대체하지 않고 클릭 시 안내 문구를 보여주는 범위로 진행함.
- 2026-11-27: 홈 API 응답의 `newProducts`를 신상품 섹션으로 표시하기로 확인했다가, 사용자가 “신상품 기능은 연결하지 말고 있는 것만 연결해”라고 정정함. 최종 범위에서는 현재 화면에 없는 신상품 기능을 연결·표시하지 않음. 홈 응답의 `banners`도 현재 히어로·프로모션 구성을 유지하고 별도 영역을 만들지 않음(사용자 답변: “기존 구성 유지 (추천) — 현재 히어로·프로모션만 표시”).
- 2026-11-27: 홈의 `popups.list`는 real mode에서 실제 `GET /api/v1/popups`로 연결하고, 홈 API 오류에는 재시도 버튼을 추가하기로 확인함(사용자 답변: “팝업 API도 연결 (추천) — 홈의 mock 팝업을 real로 바꾸지만 slice 범위가 넓어짐”; “재시도 버튼 추가 (추천) — 실패 후 복구 흐름을 보강”).

## 후속 확인 항목

- 상품 상세 API는 옵션 그룹 대신 flat SKU 목록을 제공하므로, 상세 화면에서 옵션을 어떻게 선택하게 할지 후속 작업에서 정합니다. 사용자 확인 전에는 옵션 그룹이나 필수 여부를 추정하지 않습니다.
- SKU `price`가 최종 SKU 가격인지 상품 기본가에 더하는 추가금인지 후속 작업에서 확인합니다. 확인 전에는 가격 의미를 추정하지 않습니다.
- 상세 API에 배송비·배송 방식·정책·구매 안내가 없습니다. 미지원 정보를 mock 값이나 기본값으로 표시하지 않습니다. 해당 기능의 기존 진입 요소를 누르면 안내 문구를 보여줍니다.
